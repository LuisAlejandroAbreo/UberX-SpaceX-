## 📝 Descripción APP UberX-SpaceX

El presente proyecto consiste en el desarrollo conceptual y maquetación de una plataforma digital para una alianza ficticia entre **UberX** y **SpaceX**. El objetivo primordial es diseñar la experiencia de usuario para la reserva de servicios de turismo intergaláctico, específicamente trayectos de punto a punto (ej. Tierra-Marte), priorizando la coherencia visual y la fluidez estética entre distintos módulos de diseño.

La implementación se limitará exclusivamente al uso de estándares modernos de **HTML5** y **CSS3**. Con el fin de demostrar dominio técnico avanzado en hojas de estilo, toda interactividad y dinamismo del prototipo se resolverá sin el uso de lenguajes de programación (JS) o frameworks externos.



## 🚀 Funcionalidades Principales

- 🪐 Presentar los destinos planetarios o satélitales
- 📅 Informar sobre próximos lanzamientos
- 🔍 Permitir visualizar el detalle de un viaje  
- 💳 Soporte para distintas tarjetas de crédito
- 🧾 Generar el recibo pertinente al viaje
